# sign-up-form

In this project I remake a sign up form that mirrors the one in the TOP curriculum. 

Key learning points: 

1. I learned about making 2 columns in this format and then spaced the children within them. 

2. I learned how to use pseudoclasses 

3. I learned how to make shadows and what each parameter means. 

4. How to style hyperlinks and remove the defalut underline. 


This was a difficult project because of all the things you have to consider at once. Spacing is 
a delicate thing that can be offset with different properties.
